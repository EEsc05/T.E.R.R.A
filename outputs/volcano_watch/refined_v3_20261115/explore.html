Choose where the history goes next.

Generate a sequence of predicted maps from the starting observation to your target date. They appear in the Forecast panel beside the globe. The model uses six dated input slots; it does not download new observations.

Local model inference

The start is the newest map in the prepared input window, not the displayed browsing date. Each date is predicted directly from that window; feedback is used only when you explicitly enable and add it.

Feeding forecasts back into the model is experimental. Errors can accumulate; it does not add new measurements or produce a calibrated confidence score.
